# 🎨 C.O.L.O.R - Python Gaming Suite

This is a collection of **5 interactive games** built in Python using **Pygame**. Created for AIE Charter School's hackathon, each letter in "COLOR" represents a unique mini-game with its own themed background color. Inspired by games like S.T.A.L.K.E.R., this project demonstrates creative acronym-based game design with engaging gameplay mechanics!

---

## 🎮 The 5 Games

Each game corresponds to a letter in **C.O.L.O.R** with matching background colors:

- **🏃 C - Chase** *(Cyan background)* - Fast-paced chase gameplay
- **🪶 O - Ostrich Catch** *(Orchid background)* - Whack-A-Mole spinoff that fits our acronym  
- **✨ L - Luminous Draw** *(Lavender background)* - Creative drawing and artistic expression
- **🏗️ O - Obby** *(Orange background)* - Obstacle course platformer with gravity and collision detection
- **🌧️ R - Raindrop Dodge** *(Red background)* - Dodge-based survival gameplay

## ▶️ How to Run

### Prerequisites
Make sure you have Python 3 installed on your system.

### Installation
1. Clone this repository:
```bash
git clone https://github.com/Xtreak-XD/C.O.L.O.R
cd C.O.L.O.R
```

2. Install Pygame:
```bash
python -m pip install pygame
```

### Running the Games

**Option 1: Complete Game Suite (Recommended)**
```bash
python ActualyGame.py
```
*Access all 5 games through the main UI interface*

**Option 2: Individual Games**
```bash
python pygame[letter]ButClass.py
```
*Replace `[letter]` with C, O, L, O, or R for specific games*
